# 四问最终入口

本目录是评委使用的稳定入口层。真正的算法源码仍保留在`../code`原位置，避免破坏Q3/Q4冻结哈希及其相对路径依赖。

| 问题 | 入口 | 直接运行时的行为 |
| --- | --- | --- |
| Q1 | `q1_entry.py` | 接收Q1输入JSON并写出结果JSON |
| Q2 | `q2_entry.py` | 接收首次测量参数并写出第二检测点结果 |
| Q3 | `q3_entry.py` | 仅离线校验strict84代码锁；供模拟器调用时提供`run_search` |
| Q4 | `q4_entry.py` | 仅离线校验FREE最终代码锁；供模拟器调用时提供`run_search` |

先在上一级目录运行`python -B -X utf8 run_all_checks.py`。Q3/Q4正式会话脚本需要明确授权和模拟器环境，不属于离线复现步骤。
